# Repeat After Me

語学学習用の音声フレーズ一覧アプリです。Android 端末内で選択したフォルダにある `.m4a` ファイル名を一覧表示し、検索できます。

## 機能

以下の機能を持っています。

- 音声ファイル名から拡張子を除いて一覧表示
- 選択した音声フォルダ内のサブフォルダを階層選択
- ファイル名、`m4a`ファイルのタイトル・アルバム・アーティストを対象にしたインクリメンタル検索
- 絞り込み検索で `?` は任意の1文字、`*` は任意の文字列（0文字以上）にマッチ
- リスト項目のタップで音声を再生し、再度タップすると一時停止
- タイトル横の連続再生ボタンでリストを連続再生し、停止ボタンで停止
- 連続再生は開始から15分後に自動停止。
- システム言語が日本語の場合は日本語、それ以外は英語で表示
- シードカラー、カラーバリエーション、システム配色の設定

## 音声ファイルの追加

端末内の任意のフォルダに、USB 経由などで `.m4a` ファイルをコピーします。アプリの設定画面の「音声フォルダ」でそのフォルダを選択してください。選択は再起動後も保持されます。

「音声ライブラリ」横のドロップダウンで、選択したフォルダとサブフォルダを切り替えます。選択したフォルダは `/`、サブフォルダはパスで表示されます。現在選択中のフォルダ直下にある `.m4a` ファイルだけが一覧に表示されます。`hello.m4a` は `hello` として表示されます。ファイルを追加したあとは、メインページの再読み込みボタンを押してください。

検索ではファイル名に加え、`m4a`ファイル内のタイトル・アルバム・アーティスト情報も対象になります。これらのメタデータはアプリ専用ストレージに索引として保存し、ファイルの更新を検出した場合だけ再解析します。更新日時が変わらずタグだけを編集した場合は、音声操作メニューから選択中フォルダの索引を再作成してください。

Android 11 以降ではストレージのルートや Download フォルダ自体は選択できないため、`Music/repeat_after_me` のようなサブフォルダを作成して選択してください。

## 開発

Flutter SDK をインストールした環境で実行します。VS Codeの場合は、Dev Container を使用すると開発環境を自動構築します。

テスト:

```sh
flutter test
```

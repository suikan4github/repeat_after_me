# Repeat After Me

語学学習用の音声フレーズ一覧アプリです。`assets/audio/` にある `.m4a` ファイル名を一覧表示し、タップして再生します。また、絞り込み検索もできます。

## 機能

以下の機能を持っています。

- 音声ファイル名から拡張子を除いて一覧表示
- 名前のインクリメンタル絞り込み検索
- リスト項目のタップで音声を再生し、再度タップすると一時停止
- タイトル横の連続再生ボタンでリストを連続再生し、停止ボタンで停止: 最後に再生した項目から始めて上から順に再生する。末尾まで再生したら次は先頭に戻る。
- 連続再生は開始から15分後に自動停止。
- システム言語が日本語の場合は日本語、それ以外は英語で表示
- シードカラー、カラーバリエーション、システム配色の設定

## 音声ファイルの追加

デフォルトでは音声ファイルは空です。`.m4a` ファイルを `assets/audio/` に追加してください。

例:

```text
assets/audio/
├── hello.m4a
└── good_morning.m4a
```

これらのファイルはアプリには `hello`、`good_morning` として表示されます。追加後にビルドを行ってください。

## 開発

Flutter SDK をインストールした環境で実行します。VS Codeの場合は、Dev Container を使用すると開発環境を自動構築します。

テスト:

```sh
flutter test
```

Web ビルド:

```sh
flutter build web
```

生成物は `build/web/` に出力されます。Web での音声再生はブラウザーの M4A/AAC 対応状況に依存します。
